Achillea

Platform under development

Achillea is a platform under development for guided outdoor play. Its reusable game and application contracts are being validated through a local-first product.

Design direction

  • Dynamic features — tutorials and flows defined as data, adaptable at runtime.
  • Reusable primitives — turns, sessions, prompts, progression modeled once.
  • Future multiplayer — turn-based coordination without heavy infrastructure is planned, not part of the first local release.
  • Low operational cost — designed for small-team ownership.

First product

Asterwild is the first product being developed using Achillea. Its initial local, account-free Pentalpha experience is in progress; a public app or SDK release is not available here.

Direction

Build one product. Extract what holds. Keep the platform small. The public repository currently hosts project documentation and this site, not the SDK. View the public repository and the proposed publication boundary.
