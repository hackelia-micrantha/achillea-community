Outdoor game catalogue and downloadable content — in development

Discover outdoor games, download the ones you want, and play offline. Achillea is being built around a growing game catalogue and downloadable content for Asterwild. Game downloads are a planned capability, not yet available.

Download games — planned

The intended experience is straightforward: browse the catalogue, choose a supported game, download its content, and keep it available offline. In-app game downloads, installation, updates and removal are not shipping features today.

  • Browse: compare game objectives, player counts and setup needs.
  • Download: acquire a compatible, reviewed content definition for a supported game.
  • Play offline: launch installed content without relying on a network connection.

The current Pentalpha reference is bundled with the private application, not downloaded. Future content packs would select trusted, already-installed gameplay capabilities; games requiring new executable rules would still require an application update.

First application — Asterwild

Asterwild is the Expo/React Native application being built to deliver Achillea's outdoor games. Its first implemented Pentalpha flow covers discovery, setup, tutorial, play, results and replay, with local session recovery.

The application, its game engine and SDK are still private and unreleased. iOS, Android and web are development targets undergoing release qualification; there is no public app installation or supported SDK yet.

How downloadable content could work

The public Shape Hunt example explores fetching a bounded, data-only activity for a renderer already included in the page. It is a technical illustration, not a catalogue download or proof of in-app game installation.

Try the standalone Shape Hunt feature illustration, read its technical walkthrough and validation boundaries, or view the architecture diagrams. The example is an independent browser demonstration, not the private product.

Direction
