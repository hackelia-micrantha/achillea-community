# Achillea community — retired surface

The canonical Achillea project has moved to **[hackelia-micrantha/achillea](https://github.com/hackelia-micrantha/achillea)**.

This repository previously hosted a public projection of documentation, a draft application-state/effect specification, conformance fixtures, and a small project site while the implementation repository was private. That split is retired: the platform, Asterwild reference/product application, specifications, tests, and documentation now have one canonical source.

## Current authority

- **Canonical source and documentation:** [hackelia-micrantha/achillea](https://github.com/hackelia-micrantha/achillea)
- **Repository model:** [docs/architecture/public-repository-model.md](https://github.com/hackelia-micrantha/achillea/blob/main/docs/architecture/public-repository-model.md)
- **Application state/effect draft:** [canonical specification](https://github.com/hackelia-micrantha/achillea/blob/main/docs/specifications/application-state-effects-v0.1.md)
- **Conformance fixture:** [canonical fixture](https://github.com/hackelia-micrantha/achillea/blob/main/docs/specifications/conformance/application-cycle-v0.1.json)

Do not file new implementation or specification work here. Existing history is retained for provenance and old links; this repository should be archived after the canonical repository is public and links are verified.

No package release or open-source license grant is implied by this migration.
